# 隐私与安全边界

Project Atlas 的设计目标不是“收集更多”，而是“让你看清本机项目，同时不把项目交出去”。

## 本地优先

- 没有账号、云端同步、遥测或远程分析。
- 项目内容只在 Host 端读取；浏览器客户端通过本机 HTTP API 获取数据。
- 插件不会自动启动 GPU、ComfyUI、训练脚本或项目命令。
- 打开工作台不会自动向 Agent 发送项目内容；必须由用户在项目页显式操作。

## 读取范围

只有在 `roots` 中显式配置的目录才会被扫描。默认 `roots: []`，首次打开是空状态，不会猜测硬盘、用户名或主目录。

扫描器读取：

- 目录名、文件列表和项目标记；
- Git 元数据（只读）；
- `SKILL.md` 和项目状态文档；
- DSH / Codex 会话元数据；
- 运行状态和产物索引。

扫描器不执行项目脚本、不读取无关的个人文件内容，也不把文件上传到网络。

## 写入范围

运行数据默认写入 `<DSH_HOME>/data/dsh-workbench/`。这些数据不会进入 npm 包或 Git 仓库。

删除功能默认关闭。开启后也只允许删除“已弃用”的顶层项目，并拒绝：

- 符号链接；
- 插件自身；
- 数据目录；
- 用户主目录及常见个人目录；
- `protectedPaths` 中的路径；
- 未经逐项确认的项目。

## 公开仓库的清洁规则

公开包不包含：

- 真实个人项目、项目名或目录结构；
- 用户名、机器名、绝对个人路径；
- 会话 ID、会话截图或聊天内容；
- 运行数据、缓存、删除日志；
- 带个人元数据的图片。

测试只使用中性 fixture（例如 `DemoProject`）。地球纹理来自 NASA 公共领域素材，来源与校验和见 [ASSET-LICENSES.md](../ASSET-LICENSES.md)。

## 已知边界

- 插件运行在用户自己的 DSH 进程中，能读取该 DSH 配置允许的本地数据；请只安装可信插件。
- 若把 `roots` 指向包含敏感文件的目录，工作台会按设计展示这些目录的项目元数据。请用最小必要的根目录。
- 本项目不提供恶意本地文件防篡改，也不替代操作系统权限、磁盘加密或备份。

## 报告问题

如果发现隐私或安全问题，请不要在公开 issue 中粘贴真实项目路径、会话内容或截图。先描述影响范围和复现条件，维护者会提供私下提交方式。
